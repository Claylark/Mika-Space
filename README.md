# 零宇・永焰鸟空间站 - 个人兴趣展示页
## 项目简介
这是一个基于 HTML、Tailwind CSS 和原生 JavaScript 开发的个人兴趣展示页面，主打 "兴趣圈展示 + 社交链接" 功能。页面融合古希腊美学元素（柱式边框、回纹装饰）与现代 UI 设计，以粉紫色为主色调，适配多设备屏幕，适合作为兴趣同好交流的个人门户。
## 核心功能模块
- 模块名称	功能说明
- 导航系统	固定顶部导航栏，含 "关于我"" 兴趣圈 ""可聊话题"" 加好友 "4 个板块，支持移动端汉堡菜单切换
- 个人展示区	头像 + 昵称 + 核心标签组合，作为页面视觉焦点，快速传递个人定位
- 兴趣圈展示	包含主推角色（横向滚动卡片）、核心兴趣标签、游戏坑列表、语擦相关信息及雷点说明
- 社交链接区	提供 QQ 号及直接添加好友的链接，降低社交门槛
- 交互动效	卡片悬停上浮、滚动渐入、导航高亮等动态效果，提升页面体验
## 技术栈
- 基础框架：HTML5
- 样式方案：Tailwind CSS v3（自定义主题配置）
- 图标资源：Font Awesome 4.7
- 交互逻辑：原生 JavaScript（滚动监听、动画控制）
- 字体资源：Google Fonts（Inter + Playfair Display）

##  替换个人信息  
- 头像：修改 `<img src="你的图片路径">` 中的路径  
- 标签：更新"我的标签"区域的 `<span>` 内容（如替换"昔涟水仙"为其他兴趣标签）  
- 联系方式：更改QQ号及链接 `<a href="你的QQ加好友链接">`
